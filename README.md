# Logistics Data Analysis Internship

## Project
Data-Driven Delivery Route and Inventory Optimization for E-Commerce Logistics

## Internship
YuvaIntern – Logistics Data Analyst Intern

## Objective
This project applies Python-based data analysis and data science
techniques to a logistics and e-commerce supply-chain scenario.

## Planned Analysis
- Data Cleaning
- Exploratory Data Analysis
- KPI Analysis
- Regression
- Clustering
- Route and Resource Optimization
- Data Visualization

## Key KPIs
- On-Time Delivery Rate
- Average Delivery Time
- Inventory Turnover Rate
- Transportation Cost per Delivery
- Order Fulfillment Rate

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
